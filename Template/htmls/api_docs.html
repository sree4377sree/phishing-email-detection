Available REST Endpoints

POST /api/v1/predict/
Classifies email text and headers using DistilBERT & Calibrated Ensemble. Returns prediction, confidence, risk score, and XAI token attributions in < 25ms.
POST /api/v1/batch-predict/
Accepts an array of emails for high-volume automated batch scanning.
GET /api/v1/metrics/
Returns evaluation benchmarks (Accuracy: 96.44%, F1: 96.64%, ROC-AUC: 99.82%), confusion matrix, and multi-model comparative statistics.
GET /api/v1/history/
Queries historical scan audit log with optional search filter ?q=keyword&limit=50.
GET /api/v1/stats/
Returns real-time scan statistics: total emails scanned, phishing count, safe count, and threat ratio.
GET /api/v1/health/
System health check confirming database and neural model readiness.
